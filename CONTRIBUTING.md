# Contributing to FS25 CropPorter

Thanks for helping test FS25 CropPorter.

This project is currently in alpha. The most useful contributions are:

- testing different field crops
- testing different source and target maps
- reporting clear FS25 log errors
- sharing preflight/apply reports
- identifying maps with unusual XML layouts
- improving documentation

## Before reporting a bug

Please confirm:

1. You used a copied target map.
2. You tested in a disposable save.
3. You removed duplicate versions of the same target map from the active mods folder.
4. You checked the generated `CropPorter_Apply.md`.
5. You checked the FS25 `log.txt`.

## Pull requests

Pull requests are welcome, but please keep v0.1 focused on standard field crops.

Plantation/vine crop work should remain separate until it is stable enough for public release.
